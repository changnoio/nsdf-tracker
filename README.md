# ระบบติดตามแผนงานกองทุนพัฒนาการกีฬาแห่งชาติ ปี 2570

[เปิดแดชบอร์ด](https://changnoio.github.io/nsdf-tracker/)

บุคคลทั่วไปดูแผนงานที่ 1–8 และรายงานย้อนหลังได้ เจ้าหน้าที่เข้าสู่ระบบด้วยบัญชีประจำกองทุนเพื่อนำเข้าและส่งออก Excel ทั้งเก้าแผน และติดตามงานจัดซื้อจัดจ้างแผน 9

## ข้อมูลร่วมกันทุกเครื่อง

GitHub Pages เชื่อม API บน Sites และฐานข้อมูล D1 กลางที่ประกาศไว้ใน `shared-api.json` ทุกเครื่องอ่านรอบที่บันทึกล่าสุดจากแหล่งเดียวกัน หน้าที่เปิดอยู่ตรวจข้อมูลใหม่ทุก 15 วินาทีและเมื่อกลับมาเปิดหน้าต่าง หากกำลังเลือกรอบย้อนหลัง ระบบคงรอบที่เลือกไว้

การนำเข้าต้องกรอกชื่อผู้บันทึก ชื่อนี้เป็นข้อมูลที่เจ้าหน้าที่แจ้งผ่านบัญชีร่วม ระบบบันทึกชื่อและเวลาจากเซิร์ฟเวอร์ลงในประวัติ และส่งออกพร้อมรายงาน Excel ผู้เข้าชมทั่วไปเห็นเฉพาะข้อมูลแผนงานที่ 1–8

เมื่อมีการบันทึกพร้อมกัน ระบบตรวจ revision และให้ตรวจผลต่างใหม่ก่อนยืนยัน ขณะส่งข้อมูลใช้รหัสคำขอเพื่อป้องกันการบันทึกซ้ำจากการส่งใหม่หลังเครือข่ายขาด

## อัปเดตรายสัปดาห์

1. เลือก **สำหรับเจ้าหน้าที่** และเข้าสู่ระบบ
2. เปิด **นำเข้าและเทมเพลต** กรอก **ชื่อผู้บันทึกข้อมูล**
3. ดาวน์โหลดแม่แบบแผน 1–9 และกรอกช่องที่เปลี่ยนตามรหัสรายการเดิม
4. เลือกวันที่และไฟล์ ตรวจผลต่าง แล้วกด **ยืนยันบันทึกรอบรายงาน**
5. ผู้ชมเครื่องอื่นเห็นรอบใหม่เมื่อเปิดหน้าเว็บ หรือภายในประมาณ 15 วินาทีขณะเปิดค้างไว้

การยืนยันสำเร็จหมายถึงบันทึกที่เซิร์ฟเวอร์แล้ว หากเชื่อมต่อไม่ได้ หน้าจอแสดงสถานะและให้ลองใหม่

## ย้ายข้อมูลที่เคยบันทึกเฉพาะเครื่อง

เปิดลิงก์เดิมด้วยเบราว์เซอร์และอุปกรณ์ที่เคยนำเข้า ลงชื่อเข้าใช้เจ้าหน้าที่ แล้วเปิด **นำเข้าและเทมเพลต** เมื่อพบประวัติเดิม ระบบแสดง **ตรวจและย้ายข้อมูลเดิม** กรอกชื่อผู้ย้าย เลือกรอบเดิม และตรวจผลต่างกับข้อมูลกลางก่อนยืนยันทีละรอบ

ข้อมูลที่ย้ายบันทึกเป็นรอบใหม่ตามวันที่เลือก พร้อมอ้างอิงวันที่เดิมและชื่อผู้ย้าย ชื่อผู้บันทึกเดิมแสดงว่าไม่ระบุ ระบบจำรอบที่ย้ายสำเร็จเพื่อป้องกันการย้ายซ้ำ ข้อมูลเดิมยังอยู่ในเบราว์เซอร์ต้นทาง

## การคำนวณ

กราฟงบประมาณแสดงยอดอนุมัติหรือยอดเบิกจ่ายเทียบกรอบวงเงินแต่ละแผน ตารางแสดงร้อยละเบิกจ่ายเทียบยอดอนุมัติแล้ว บัตรเบิกจ่ายภาพรวมคำนวณเฉพาะแผนที่แจ้งยอด ช่องที่ต้นทางเว้นว่างหรือไม่มีฐานคำนวณแสดง —

## พัฒนาและเผยแพร่

ใช้ Node.js 24 ขึ้นไป `npm start` เปิดรุ่นบนเครื่องที่ [localhost](http://127.0.0.1:4190/) รุ่นนี้ใช้ SQLite ใน `.local-data/` สำหรับพัฒนาทดสอบ

- `node scripts/build-pages.mjs` สร้าง frontend ที่ `_site/` พร้อม URL ฐานข้อมูลกลาง
- Push สาขา `main` จะเริ่ม workflow เผยแพร่ frontend บน GitHub Pages
- `node build.mjs` สร้าง Worker ที่ `dist/server/index.js` สำหรับ Sites โดยใช้ D1 binding ชื่อ `DB` และ migrations ใน `drizzle/`
- เมื่อแก้ `api.mjs`, `worker.mjs`, `dist/core.js` หรือข้อมูลฐาน ต้องเผยแพร่ Worker บน Sites ด้วย การ push GitHub เผยแพร่เฉพาะ frontend

ซอร์สของ frontend และ backend อยู่ในคลังนี้ ข้อมูลรายสัปดาห์อยู่ในฐานข้อมูลกลางและคงอยู่ข้ามการเผยแพร่ ไฟล์ตั้งต้นแผน 9 เข้ารหัสใน `dist/staff-data.js` เปิดหลังเข้าสู่ระบบ ประวัติ Git ของรุ่นก่อนปรับสิทธิ์ยังคงอยู่
