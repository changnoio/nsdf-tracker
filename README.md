# ระบบติดตามแผนงานกองทุนพัฒนาการกีฬาแห่งชาติ ปี 2570

[เปิดแดชบอร์ด](https://changnoio.github.io/nsdf-tracker/)

บุคคลทั่วไปเลือกดูแผนงานที่ 1–8 งบประมาณ MOU ยอดเบิกจ่าย และรายงานย้อนหลังได้ เจ้าหน้าที่เข้าสู่ระบบด้วยบัญชีประจำกองทุนเพื่อนำเข้าและส่งออก Excel ทั้งเก้าแผน และติดตามโครงการจัดซื้อจัดจ้างแผน 9

## อ่านตัวเลขบนแดชบอร์ด

กราฟงบประมาณแสดงยอดอนุมัติหรือยอดเบิกจ่ายเทียบกับกรอบวงเงินแต่ละแผน ส่วนตารางแสดงร้อยละเบิกจ่ายเทียบกับยอดที่คณะกรรมการอนุมัติแล้ว บัตรเบิกจ่ายภาพรวมคิดจากแผนที่แจ้งยอดเท่านั้น ช่องที่ต้นทางเว้นว่างและสัดส่วนที่ไม่มีฐานคำนวณแสดงเครื่องหมาย — การเลือกรอบรายงานมีผลกับตัวเลข ตาราง และรายงานส่งออก

## อัปเดตประจำสัปดาห์

1. เลือก **สำหรับเจ้าหน้าที่** และเข้าสู่ระบบ
2. เปิด **นำเข้าและเทมเพลต** เลือกเทมเพลตแผน 1–9 และกรอกเฉพาะช่องที่เปลี่ยนตามรหัสรายการเดิม
3. เลือกวันที่รายงานและไฟล์ ตรวจผลต่าง แล้วกด **ยืนยันบันทึกรอบรายงาน**
4. เปิดรายแผนหรือรายงานรายสัปดาห์เพื่อดูผล หรือกด **ส่งออกรายงาน** เพื่อดาวน์โหลด Excel

## การเก็บข้อมูลและการเผยแพร่

GitHub Pages เก็บรอบนำเข้าในเบราว์เซอร์บนอุปกรณ์ที่บันทึก ผู้เข้าชมจากเครื่องอื่นเห็นข้อมูลฐานที่เผยแพร่บน GitHub การอัปเดตสาขา `main` จะเริ่ม workflow เผยแพร่ Pages และสามารถสั่งรันด้วยตนเองในแท็บ Actions ได้

ข้อมูลฐานแผน 1–8 อยู่ใน `dist/data.js` ข้อมูลและเทมเพลตแผน 9 ของรุ่นปัจจุบันอยู่ใน `dist/staff-data.js` ซึ่งเข้ารหัสด้วย AES-GCM และใช้ PBKDF2 แปลงรหัสผ่านเป็นกุญแจ เบราว์เซอร์เปิดข้อมูลส่วนนี้หลังเข้าสู่ระบบ สิทธิ์หมดเมื่อออกจากระบบหรือรีโหลดหน้า ประวัติ Git ของรุ่นที่เผยแพร่ก่อนปรับสิทธิ์ยังคงอยู่

## ใช้งานบนเครื่อง

ใช้ Node.js 24 ขึ้นไป รัน `npm start` หรือดับเบิลคลิก `เปิดแดชบอร์ด.cmd` บน Windows แล้วเปิด [เว็บบนเครื่อง](http://127.0.0.1:4190/) รอบที่นำเข้าเก็บใน `.local-data/weekly.sqlite` ทุกหน้าต่างที่ใช้เซิร์ฟเวอร์เดียวกันเห็นประวัติชุดเดียวกัน ตั้ง `NSDF_DATA_DIR` และ `NSDF_PORT` ได้ตามต้องการ

ทดสอบการสร้างชุดสำหรับ Pages ด้วย `node scripts/build-pages.mjs` ผลอยู่ใน `_site/` ส่วน `node build.mjs` ใช้สร้าง Worker สำหรับสภาพแวดล้อม D1 ที่ตั้ง binding ชื่อ `DB`
